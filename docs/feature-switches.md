# 功能开关

设置页的「功能」区域提供 DNS 和 ModelExtMCP 两个独立开关，切换后立即保存并生效。新安装与旧版本升级后均默认开启。

关闭 DNS 后隐藏导航入口，停用 DNS 接口并停止后续定时检查。原有定时设置、凭据和检查历史保留，重新开启后按原定时间隔重新计时。已发出的远端请求可能完成，停用后尚未开始的 DNS 写入会被拒绝。

关闭 ModelExtMCP 后隐藏导航入口，停用管理接口与 MCP 新请求，包括已有会话发起的后续请求。配置、调用凭据及历史数据保留。已经受理的调用可以完成。

通过书签访问关闭的功能会显示提示，可返回设置重新开启。开关由服务端保存，对所有浏览器生效，其他已打开的浏览器会在重新获取设置时更新导航。关闭期间后端直接拒绝功能请求。

## 实现与验证

开关保存在 `app_settings.dns_enabled` 与 `app_settings.model_relay_enabled`，数据库迁移 v13 默认值均为 1。`PATCH /api/settings` 接收可选布尔字段 `dnsEnabled` 与 `modelRelayEnabled`，省略字段保持原值。禁用接口返回 HTTP 503，错误码为 `feature_disabled`。

服务端统一请求检查覆盖 DNS、Model Relay 与 MCP 路径。DNS 调度在启动、保存设置和功能开关变更时应用有效状态，执行路径在等待互斥锁后及写入前再次检查开关。

自动测试覆盖默认值、迁移、部分更新、接口拒绝、调度恢复和写入前停用，以及前端开关保存与导航状态。
