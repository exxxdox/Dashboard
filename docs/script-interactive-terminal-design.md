# 脚本交互终端设计

状态：已实现，通过自动化测试与真实 SSH/PTY、浏览器验收。日期：2026-11-11。

## 目标与范围

在现有脚本执行系统中新增可选的「交互运行」，允许脚本直接使用终端输入：文字、回车、方向键、密码提示及 Ctrl+C。运行详情页继续使用现有 xterm，保持脚本、目标主机、运行记录、并发队列、超时、取消和通知的统一生命周期。

普通运行和定时任务继续使用现有非交互路径。交互终端仅执行所选脚本，不另开通用 SSH 登录 shell；脚本自身允许的命令和子进程仍具有目标账号权限。

## 方案比较

- 按行输入：改动较小，但不能正确支持需要 TTY 的菜单、密码提示、方向键与屏幕重绘，未选用。
- SSH PTY + 现有 xterm：用户已选择完整终端；已有 ssh2、xterm、fit 插件与 WebSocket，无需引入终端依赖，选用。
- 所有执行统一改为 PTY：会改变日志流、缓冲与无人值守脚本行为，不采用。

## 用户行为

1. 手动运行设置新增「交互终端」开关，默认关闭，保存到手动运行草稿；一键运行沿用保存设置。定时任务不提供该开关，API 拒绝交互定时任务。
2. 提交后进入运行详情；排队、连接和上传阶段不可输入，PTY 就绪后可以输入。终端显示连接及控制状态，中英文文案沿用项目字典。
3. 支持 xterm 的键盘与粘贴输入、方向键、回车和终端尺寸变化。提供可访问的 Ctrl+C、Ctrl+D 按钮以兼容移动端。Ctrl+C 发往终端，由前台程序处理；「取消执行」继续是强制停止任务的独立动作。
4. 同一执行只允许一个 WebSocket 连接控制输入和尺寸。第一个申请成功的页面获得控制权，其他页面只读；持有者离开、断线或任务结束后释放，其他页面可以主动申请。用户刷新可在旧连接释放后重新申请。
5. 关闭页面不会取消脚本；运行在服务器中继续，到退出、超时或显式取消。WebSocket 断线期间禁用输入，不排队、不重发未确认的键盘输入，避免重复执行。
6. 运行结束后终端只读，展示退出状态和历史输出。服务器重启仍按现有规则将未完成任务标记 interrupted，不保证保留远端会话。

## 数据与协议

共享契约为手动运行输入、运行草稿和 ExecutionSummary 增加 interactive 标记，默认 false；数据库对 executions 增加默认 0 的列，以区分历史与普通运行。旧草稿和旧客户端继续正常使用。沿用现有迁移机制，不修改历史迁移。

沿用已认证的 /api/ws，并扩展显式的终端申请/释放、input、resize 消息及状态/错误响应。已有日志订阅继续负责输出和按 seq 补全，不再创建第二份输出存储。输入仅能发往已订阅且持有控制权、PTY 已就绪的交互执行。所有消息在边界用 zod 验证；限制消息体、输入字节数、终端行列范围和待写入缓冲，尊重 SSH 背压；超限明确拒绝，不静默截断。

校验 WebSocket Origin 与实际服务来源一致，沿用会话认证；拒绝跨站浏览器连接，不信任未经配置的转发头。敏感输入不进入应用日志、数据库、通知或错误文本。脚本的终端回显仍属于输出并会被保存，不能保证任意脚本输出的密码被自动识别或脱敏。密码输入是否回显由远端程序的终端设置决定。

## 执行与资源归属

- ExecutionService 负责运行模式校验和快照；队列并发规则保持一致，交互运行也占用普通执行槽。
- Runner 持有执行期的终端控制句柄注册表，执行结束时无条件移除；服务层验证 execution id、交互标记与运行状态，路由只做协议和连接控制权管理。不在 WebSocket 生命周期中拥有远端执行。
- 扩展现有 Transport 执行选项和终端句柄（写入、resize），不引入新的 transport 或独立终端服务体系。
- 交互模式先通过同一 SSH 连接的非 PTY 通道将提交时快照的脚本字节写入现有独占 stagingDir，确认完整上传并关闭通道，再开启 PTY 执行。上传失败不得启动脚本。整个上传过程也必须受取消和同一次运行的超时约束。
- PTY 请求 xterm-256color，初始尺寸使用固定合理值，控制页连接后更新；不支持 PTY 的主机明确失败，不降级成假交互。
- 单独构建交互执行命令，复用 shell.ts 的参数、环境变量和路径引用规则。交互调用保留 PTY stdin，不能继承普通执行的 /dev/null 重定向。默认 PowerShell 交互路径去掉 -NonInteractive，自定义解释器保持用户配置。
- 保持 PTY 的 controlling terminal 与前台进程组，不能简单套用普通执行的 setsid 包装。远端启动标记必须被协议层识别并从输出隐藏，且在允许键盘输入前建立可取消的进程标识。取消、超时、上传中止、通道错误均清理终端句柄和 stagingDir。实现时以真实 PTY 测试证明 Ctrl+C 与取消能正确停止脚本及常见子进程；无法证明时不宣称完成。
- PTY 将 stdout/stderr 合并，作为 stdout 写入现有日志，保留 ANSI 控制序列供 xterm 渲染。系统状态文字不冒充脚本输出。

## 重连与历史的边界

复用当前日志历史与实时 seq 补全。恢复输出期间 xterm 禁止输入，避免回放控制序列触发终端回复而误发给脚本；控制恢复后才能接收用户输入。

已有 MAX_LOG_BYTES 上限保持不变。超过上限后实时输出仍继续，但刷新只能恢复已保存部分和之后的实时内容，显示截断提示；不承诺精确恢复全屏程序当前画面。历史没有保存每次 resize 的时间线，因此尺寸变化或全屏程序的历史回放也不保证像素一致。此次不增加屏幕快照、无限日志或远端 tmux 依赖。

## 涉及文件范围

- packages/shared：执行/草稿/消息契约、shell 命令与解释器调用、边界测试。
- apps/server：数据库迁移、executions 服务、runner、transport 及 fake transport、WebSocket 路由、必要的配置与组装，以及对应测试。
- apps/web：手动运行设置与草稿转换、一键运行、详情终端、WebSocket 客户端、连接状态和双语文案，以及对应测试。
- 文档：本设计落地后更新为行为与边界说明；AGENTS.md 和 CLAUDE.md 同步更新并保持字节一致。

## 验收结果

- 共享包 114 项、服务端 503 项、前端 288 项测试通过，包含 11 项真实 SSH/PTY 测试，无跳过项。
- SSH 实测覆盖 TTY 检测、文字与原始方向键、密码关闭回显、resize、Ctrl+C / Ctrl+D、运行和上传阶段的取消/超时、子进程清理、上传失败拒绝执行、启动确认前断开不执行。
- 浏览器通过桌面及 390px 移动视口验证，覆盖手动开启、刷新恢复等待中的提示、WebSocket 断线禁用与重连、多页面只读/主动接管、密码不进入输出及历史、结束后只读；无相关控制台错误。
- 输入单条最多 16 KiB UTF-8，SSH 待写入最多 64 KiB；WebSocket 消息最多 64 KiB，尺寸限定 2..500 行/列。控制连接超过 60 秒无消息释放；浏览器每 20 秒心跳。
- 非交互运行及定时任务回归通过。PowerShell 默认交互命令已去掉 -NonInteractive 并由单元测试覆盖；验收环境未安装 pwsh，未做 PowerShell 实机交互验证。
- 需要重新构建并重启部署才会使用新功能；本次未操作线上部署。


## 终端异常关闭排查与交互修正

- 终端内的 Esc 交给当前程序处理，保留菜单和编辑器的正常操作。焦点位于页面其他位置时，Esc 仍返回运行列表。
- WebSocket 重新订阅时立即读取最新运行状态。脚本在浏览器断线期间结束，重连后也会显示最终结果。
- 交互终端工具栏显示成功、失败、超时、取消或中断，并显示退出码或信号。SSH 通道缺少退出状态时，运行记录明确报告连接可能中断。
- Dashboard 重启后，未完成任务按现有规则标记为中断。页面会解释终端会话已丢失，重新运行前需要核对目标主机上的结果。

`docker.sh --only-registry` 在更新镜像仓库配置后会重启 Docker 服务。如果 Dashboard 容器部署在同一目标主机上，Docker 重启可能同时中断 Dashboard、SSH 连接和终端会话。浏览器重连可以恢复已保存的输出与最终状态，跨 Dashboard 重启的远程 PTY 续接仍不受支持。排查时先核对本次运行的退出码、最终状态和最后输出。

本次验证覆盖真实 SSH/PTY 下嵌套 Bash 进程替换、两轮方向键菜单及后续文字输入，浏览器覆盖终端 Esc、等待输入时重连、断线期间结束、成功与失败退出码、超时，以及 Dashboard 进程重启后的中断状态。安装脚本本身的配置写入和 Docker 服务重启需在实际目标环境中核实。

## 终端内查找、链接与字符宽度

浏览器自带的 Ctrl+F 无法搜索 xterm 自绘的缓冲区，因此终端使用官方 `@xterm/addon-search` 提供查找：工具栏的搜索按钮或 `Ctrl+Shift+F` 打开输入框，Enter / Shift+Enter 切换下一个和上一个，Esc 仅关闭搜索并交回终端焦点；匹配高亮读取主题 token，并在输入框右侧显示当前序号和总数。搜索范围是本地缓冲区，即已回放的历史加上实时输出，不包含服务端因 `MAX_LOG_BYTES` 已丢弃的部分。

链接使用 `@xterm/addon-web-links` 识别输出中的 URL。输出由脚本控制，因此只有 `http(s)` 会被打开，并使用 `noopener,noreferrer` 打开新标签页；其他协议忽略。

字符宽度使用 `@xterm/addon-unicode11`，解决中文、emoji 与 Powerline 字符的列宽错位。三项都在终端创建时加载，卸载时随 `terminal.dispose()` 一并释放。渲染器仍为 xterm 默认的 DOM 渲染器，达到性能瓶颈时再评估 WebGL，当前不预先引入。

字体由用户手动输入本机已安装的字体名称，字号可调（8–32，默认 14）；工具栏提供字体面板和常见等宽字体的候选列表。输入会规范成 CSS 字体栈，主题等宽栈始终作为后备，因此字体未安装时仍是可读的终端。字体是查看设备的能力，偏好保存在 `localStorage`（`dashboard.terminal.fontFamily` / `dashboard.terminal.fontSize`），不进入服务端共享设置。运行时只改 `fontFamily` / `fontSize` 选项并重新 fit；持有控制权的页面随后发送新的行列数，避免远端 PTY 与画面不一致。不枚举本机字体，也不内嵌 webfont。
